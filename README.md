# XLSX Parser API (Flask) — ТЗ

## 1) Назначение

Нужна одна API-ручка, которая принимает `.xlsx` файл (через `multipart/form-data`), парсит таблицу по зафиксированным правилам и возвращает данные в JSON для использования на фронтенде (React).

---

## 2) API контракт

### Endpoint

`POST /api/v1/xlsx/parse`

### Content-Type запроса

`multipart/form-data`

### Поля form-data

- `file` (обязательно): загружаемый файл `.xlsx`. Структура файла у вас есть. ИИ подсказал использовать библиотеку openpyxl для чтения excel файлов.

---

## 3) Ответы

### Успех: `200 OK`

`Content-Type: application/json; charset=utf-8`

Рекомендуемая структура ответа:

```json
{
  "competences": [
    {
      "name": "Клиентоориентированность",
      "value": 3
    },
    {
      "name": "Competence 1",
      "value": 4
    },
    {
      "name": "Competence 1",
      "value": 5
    }
  ],
  "минимальный профиль": [], // аналогичная структура (опционально)
  "целевой профиль": [] // аналогичная структура (опционально)
}
```
